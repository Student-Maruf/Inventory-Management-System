# Inventoryy Management System (C)
A simple console based Inventory Management System developed using the c programming language . It allows users to manage product information , maintain stock record , and perform basic inventory operations using file handeling . 

# Features
- Add new product 
- Display all products
- Search product by ID 
- Update product information 
- Delate product 
- Store record permanantly using file handlig

## Technology Used 
- C Programming 
- Stuructures and Functions
- Arrays and Pointer 
- File Handling 

## How to Run 
1. ### Clone the repository 
    https://github.com/Student-Maruf/Inventory-Management-System/blob/main/inventoryManagementSystem.c 

2. ### Compile 
    gcc inventorymanagementsystem.c -o inventory 

3. ### Run
     inventory.exe
